# DefSeg-AM **v6** 실험 결과

> 2026-11-17 작성, 2026-11-18 에 전수 학습과 ORNL 비교를 더했다. 설계와 판정 기준은 [PLAN_v6.md](PLAN_v6.md), 실행 방법은 [docker/README.md](docker/README.md).
> run 이름: `vitb14_reg_dpt_dual_sz1036_10cls_v6` (DINOv2 ViT-B/14 reg frozen + DPT decoder, 입력 1036², `pbf-2026.11` 10-class).
> 학습 데이터는 Peregrine 사람 주석 125 레이어를 새 체계로 옮긴 것 (`ORNL_Data/DSCNN_Dataset_pbf-2026.11`) 뿐이다. DSCNN 예측은 학습 · 길이 · ckpt 선정에 쓰지 않았다.

이 문서에서 쓰는 말:

- **IoU** — 정답과 예측이 겹치는 넓이 ÷ 둘을 합친 넓이. 1 이면 완전히 같다. **결함 mIoU** 는 결함 클래스 8종의 IoU 평균이다.
- **재현율 / 정밀도** — 정답 화소 가운데 찾은 비율 / 예측한 화소 가운데 맞은 비율.
- **EMA** — 학습 중 가중치의 이동 평균 (decay 0.999). 저장하고 채점하는 것은 이 사본이다 (`last.pt`).
- **1036² / 원본 해상도** — 앞은 모델 입력 크기에서 채점한 값 (학습 곡선과 같은 해상도), 뒤는 예측을 사진의 원래 크기로 되돌려 채점한 값 (서빙과 같은 경로 — 주 지표).
- 클래스 약어: Pow Powder · Prt Printed · IS Incomplete Spreading · PS Powder Slumping · RS Recoater Streaking · RH Recoater Hopping · SE Super Elevation · SP Spatter · OM Over Melting · DB Debris.

P0 에서 확인한 것:

1. **배선이 맞다.** 클래스별 화소 수 · 레이어 수가 계획의 표와 한 화소까지 같다.
2. **정의가 그대로인 클래스는 v5 와 같다.** RS · RH · SE · DB 가 같은 22 레이어를 뗀 v5 모델과 0.01 안쪽이다. 클래스 체계를 바꾸고 Copy-Paste 에 위치 규칙을 넣은 것이 기존 성능을 건드리지 않았다.
3. **새 정의도 배워진다.** 결함 8종이 모두 복사 기준선 위다. PS 0.96, Soot 를 합친 SP 0.67, IS 와 PS 를 서로 바꿔 낸 화소는 0.5% 다.
4. **IS 와 OM 은 낮고, 원인이 데이터에 있다.** IS 는 재현율 0.24 다 (학습 6 레이어, 검증 2 레이어). OM 은 원본 해상도 0.170 이고, 학습 화소의 절반이 "Soot 로 칠한 영역 안의 파트" 두 장이다 (§1.5).

inlayer 의 값은 **낙관적**이다 (검증 레이어와 같은 빌드의 다른 레이어가 학습에 있다). 성능으로 옮겨 적지 않고, 배포 판단이나 v4 와의 우열 판단에 쓰지 않는다.
결함 mIoU 0.533 을 v5 `inlayer` 의 0.45 와 견주지 않는다 — 클래스 구성이 다르다 (PS 0.96 이 평균을 올린다). 클래스별로 견준다.

ORNL 비교에서 본 것 (전수 학습 모델. 사진을 보고 적은 것이고 사람의 확인 전이다 — §3.4):

1. **v6 의 예측은 DSCNN 과 화소의 95.2% 가 같다.** 파트 영역은 네 모델이 같은 수준이다 (CAD 파트 마스크와의 IoU 0.80–0.81).
2. **v5 와 가장 크게 다른 것은 Spatter 다.** v6 는 DSCNN · v4 와 같은 자리에 낸다 (전체 화소의 4.9%, DSCNN 4.3%). v5 는 Soot 를 배우지 않아 거의 내지 않는다.
3. **v4 의 굵은 RS 띠 · IS 띠 · Under Melting 이 v6 에는 없다.** v6 는 IS · PS · RH 를 거의 내지 않았다 — 없어서인지 못 찾아서인지는 알 수 없다.
4. **고칠 곳 셋.** RS 가 토막 난 선으로 나온다 (행 폭의 0.14, DSCNN 0.90). Debris 의 6분의 1 이 카메라 쪽에 붙은 점 세 개다. B2 의 과용융 블록에서 OM · Debris · SP 가 모델마다 갈린다.

### 1.5 약한 곳 — 레이어 단위로 본 것

검증 22 레이어에 v6 · v5 모델을 다시 돌려 레이어별 혼동 행렬을 냈다 (합계가 공식 채점과 한 화소까지 같다).
근거 그림: [p0_key_layers.png](../figures/vitb14_reg_dpt_dual_sz1036_10cls_v6/v6/cv/inlayer/p0_key_layers.png) (네 레이어 × [두 사진 · 정답 · v6 · v5]).

- **IS — 두 장으로 정해졌고 한 장을 거의 다 놓쳤다.**
  - L21 `0000015` 의 쐐기 모양 미도포 영역 (876 K px, 원본 해상도 검증 화소의 53%) 은 5% 만 찾았다. v5 모델도 같은 자리에서 5% 다. 학습에 같은 모양은 L21 `0000019` 한 장뿐이다.
  - GP `0000004` (760 K px) 는 46% 를 찾았는데 경계선 근처만이고, 채운 영역의 안쪽은 Powder 로 낸다 (v5 는 선만 냈다 — 4%).
  - 못 찾은 IS 는 다른 결함이 아니라 Powder 가 된다 (71%). 기존 IS 를 IS / PS 로 나눈 판정 때문이 아니다.
  - 학습 레이어가 6장이라 Peregrine 주석만으로는 이 클래스를 더 올리기 어렵다고 본다.
- **OM — 이 fold 로는 판단할 수 없다.**

### 1.6 이 결과가 말하지 않는 것

- 한 번의 실행 (seed 42) 이다. 클래스별 0.01–0.02 차이에는 의미를 두지 않는다 (마지막 2,000 step 동안 검증마다 흔들린 폭이 표준편차 0.001–0.005 다).
- 다른 장비 · 다른 빌드에서의 성능이 아니다. v5 는 같은 구성으로 inlayer 0.45, 장비를 통째로 뺐을 때 0.18 이었다.
- TTA · 후처리를 켠 채점은 하지 않았다 (주 지표는 둘 다 끈 값이다).
- 기존 IS 의 IS / PS 판정 (D4) 은 사람의 확인 전이다. 판정이 바뀌면 IS · PS 의 값이 바뀐다.

### 2.3 학습에 쓴 레이어를 얼마나 맞히는가 — 암기 정도이지 성능이 아니다

검증을 떼지 않은 모델이 멀쩡한지 보려고, 학습에 쓴 125 레이어를 그대로 채점했다 (`DEFSEG_V6_PHASE=trainfit`, TTA · 후처리 없음. GPU 가 비지 않아 CPU 로 10분 34초).
본 적이 있는 레이어의 점수라서 새 레이어에서의 성능과는 다른 값이다. 아래에서 읽을 것은 "무엇을 외우지 못했는가" 다.

결함 정답 화소의 99.4% 를 맞혔고 (놓침 0.4%, 다른 결함으로 0.1%), 정상 정답을 결함으로 낸 것은 2.0% 다 (원본 해상도).

- **모델은 멀쩡하다.** 학습한 레이어를 결함 mIoU 0.81 로 되돌려 낸다. ckpt (EMA 사본) 가 제대로 저장됐다.
- **P0 에서 낮았던 IS · OM · RS 는 외울 수는 있다** (0.97 · 0.87 · 0.84). P0 의 낮은 값 (0.26 · 0.45 · 0.42) 은 모델이 그 모양을 그리지 못해서가 아니라
  본 적 없는 레이어로 옮겨 가지 못해서다. IS 가 있는 레이어는 9장, OM 은 20장뿐이다.
  - RS 는 원본 해상도에서도 0.81 이다. §1.5 에서 "가는 선의 해상도 문제" 라고 적었는데, 해상도만으로는 P0 의 0.26 이 설명되지 않는다. 처음 보는 레이어에서 줄을 찾는 쪽이 더 큰 몫이다.
    다만 줄이 가장 가는 L21 (ORNL 빌드와 같은 기종) 은 외운 레이어에서도 0.64 다 (다른 소스 0.73–0.91).
- **RH 는 외운 레이어에서도 0.44 다** (재현율 0.98, 정밀도 0.44). 정답은 가는 선이고 예측은 띠 전체다. P0 의 0.35 는 일반화가 아니라 이 차이에서 온 값이다 (§1.5 와 같은 결론).
- **외운 레이어에서도 정답보다 넓게 칠한다.** 재현율은 모든 클래스가 0.94 를 넘고, 정밀도가 낮다 (RH 0.44, DB 0.69, SP 0.74, RS 0.83).
  class weight 가 그쪽으로 기울인다고 본다 (Claude 의 해석 — 따로 실험하지는 않았다): Powder 0.58 에 견줘 SP 6.1, RH 9.6, 나머지 결함 10 이라
  결함일 가능성이 6–9% 만 넘어도 결함으로 내는 편이 loss 가 작다. ORNL 사진에서 SP 를 고리 안쪽까지 채우는 것 (§3.4-1) 도 같은 성질일 수 있다.

### 2.4 이 모델에 대해 말할 수 있는 것

- **일반화 성능을 잰 값이 없다.** 검증을 떼지 않았으므로 이 모델의 점수는 없다. 가장 가까운 추정은 같은 설정으로 22 레이어를 뗀 P0 의 값이다
  (결함 mIoU 0.533 @ 1036², 0.467 @ 원본 해상도). 그 값도 낙관적이다 (§0).
- P0 모델과 달라진 것은 학습 레이어 22장이 더 들어간 것 하나다. 길이 · 설정 · seed 가 같다.
- ORNL 사진에서 어떻게 나오는지는 §3 에 있다 — 점수가 아니라 다른 모델과 견준 것이다.
- D10 (Soot 가운데 파트 안쪽을 OM 으로) 이나 D4 (기존 IS 의 판정) 를 바꿔 데이터셋을 다시 변환하면 이 모델도 다시 학습해야 한다 (114분).

### 3.4 그림에서 본 것

수치는 100 레이어 전부에서 낸 것이다. 그림은 쪽 20장 가운데 9장 (45 레이어 — 1 · 5 · 8 · 9 · 12 · 13 · 14 · 17 · 20쪽) 과 개요 한 장을 눈으로 보았고, 눈에 띈 일곱 군데를 원본 해상도로 잘라 확인했다. 나머지 11장은 타일이 비어 있지 않은지와 색만 자동으로 확인했다.

1. **v6 는 Spatter 를 DSCNN · v4 와 같은 자리에 낸다. v5 는 내지 않는다.**
   - 전체 화소의 4.93% 다 (DSCNN 4.27%, v4 6.43%, v5 0.006%). DSCNN 이 SP 로 낸 화소의 73% 를 v6 도 SP 로 냈고, v6 의 SP 화소의 64% 가 DSCNN 의 SP 다. 나머지는 서로 Powder 로 낸 곳이다 — 번진 영역의 가장자리를 어디까지 칠하느냐의 차이다.
   - v5 와 갈리는 까닭은 학습 라벨이다. v6 는 Soot 주석을 SP 로 배웠고 (SP 학습 화소의 89%), v5 는 Soot 를 미레이블로 두고 배웠다. v5 는 같은 자리를 Powder (84%) · Printed (9%) · Debris (5%) 로 낸다.
   - 빌드에 따라 넓이가 다르다. B4 는 v6 가 DSCNN 보다 좁다 (9.8% / 13.6%). B1 · B5 는 넓다 (3.3% / 1.1%, 2.5% / 0.4%) — v4 (3.2%, 1.1%) 와 비슷하거나 더 넓다.
   - B1 · B5 에서 넓은 것은 얇은 고리 둘레다. DSCNN 은 고리의 테두리만 SP 로 내고, v6 는 고리 안쪽과 옆으로 번진 영역까지 채운다 (B5 2807, B2 2087). 용융 직후 사진에서 그 고리 둘레가 주변보다 어둡기는 하다. 어디까지가 Spatter 인지는 사람이 정해야 한다.
   - v6 는 분말 위에 흩어진 작은 검은 점도 SP 로 낸다 (B2 2087 — 용융 직후 사진에 점들이 보인다). DSCNN · v4 는 그 점들을 내지 않는다.
2. **RS 는 토막 난 선으로 나온다.**
   - DSCNN 은 줄을 판의 끝에서 끝까지 잇고 (행 폭의 0.90), v6 는 0.14 다. v5 도 0.17 이라 클래스 체계가 아니라 사람 GT 만으로 배운 모델의 공통점이다.
   - 대신 줄이 있다고 본 행은 v6 가 더 많다 (레이어당 48 / 11). B5 891 을 잘라 보면 도포 직후 사진에 가는 가로줄이 판 전체에 촘촘하다. DSCNN 은 굵은 줄 셋만 끝까지 그었고, v6 는 옅은 줄까지 냈지만 군데군데 끊겼다.
   - 그래서 두 모델의 RS 가 겹치는 정도가 낮다 (IoU 0.23). 줄의 위치가 달라서가 아니라 길이와 굵기가 달라서다.
   - 까닭 (2026-11-18 에 따로 쟀다. 굵기 · 겹침은 100 레이어, 확률과 사진의 줄 세기는 25 레이어):
     - **확신이 낮아서 끊기는 것이 아니다.** v6 는 RS 로 낸 화소에서 확률이 평균 0.84 다. DSCNN 의 RS 화소 가운데 38% 는 0.5 를 넘고 55% 는 0.1 에도 못 미친다 — 그 사이는 7% 뿐이다.
       문턱을 0.05 까지 낮춰도 DSCNN RS 의 49% 까지만 겹치고 선은 이어지지 않는다 (행 폭의 0.15).
     - **v6 는 줄이 보이는 구간을 낸다.** 사진에서 그 행이 위아래 행보다 얼마나 어두운지를 재면, v6 와 DSCNN 이 함께 낸 화소의 72% 에서 줄이 잡음 위로 보인다 (잡음의 2배 이상).
       v6 가 놓친 DSCNN 선 화소에서는 42% 다 — 58% 는 줄이 잡음과 구별되지 않는 자리다. DSCNN 은 보이는 줄을 판 끝까지 이어 긋는다. 다만 놓친 것의 16% 는 줄이 뚜렷한 자리라, v6 가 실제로 놓치는 구간도 있다.
     - **사람 주석이 그렇게 생겼다.** L21 (ORNL 빌드와 같은 기종) 의 RS 주석은 굵기가 1842² 기준 3.2 px 이고, 줄이 있는 행에서 행 폭의 0.24 만 칠해져 있다. v6 의 출력 (굵기 4 px, 행 폭의 0.14 — 빌드에 따라 0.09–0.23) 은 배운 주석을 닮았다. DSCNN 의 선은 6 px 다.
     - 근거 그림: [why_bold_faint_B5_0891.png](../figures/vitb14_reg_dpt_dual_sz1036_10cls_v6/v6/full/ornl_random100_last/why_bold_faint_B5_0891.png) (B5 891 의 한 조각 — 사진, 줄의 세기, 네 모델의 예측, v4 · v5 · v6 의 RS 확률).
3. **v4 의 굵은 띠가 v6 에는 없다.**
   - v4 는 19 레이어에서 IS 를 띠 모양으로 냈다 (1,000 화소 넘게 낸 레이어 수. 모두 273 K px, 주로 B3). v6 는 그 화소의 97% 를 Powder 로 낸다. B3 3046 을 잘라 보면 그 자리에는 가는 줄 하나가 지나가고, v6 · v5 는 그 줄을 RS 로 가늘게 냈다.
   - v4 의 RS 는 v6 의 3.6배 넓이다 (2.92% / 0.81%). B3 의 앞쪽 레이어에서는 분말 위에 덩어리 모양으로도 나온다 (9쪽).
   - **v4 는 DSCNN 을 부풀린 것이다** (2026-11-18 에 따로 쟀다). v4 의 RS 는 DSCNN RS 의 97.5% 를 품으면서 넓이가 2.7배고 (선 굵기 8 px / 6 px), SP 는 98.9% 를 품으면서 1.5배다 (늘어난 SP 의 88% 가 DSCNN SP 에서 10 px 안쪽).
     v4 만 낸 RS 화소의 71% 는 사진에서 줄이 보이지 않는 자리다. v4 는 결함에서 먼 분말에서도 RS 확률이 평균 9.8% 다 (v5 · v6 는 0.07%) — 확률을 다 더하면 실제로 낸 넓이의 3.5배다.
     Stage 1 의 loss 가 확률을 부풀렸다고 본다 (Claude 의 해석): class weight (결함 최대 10, Powder 0.35 안팎) 에 focal (γ 2) 을 곱한 loss 는, 이진 근사로 계산하면 진짜 확률 0.1% 인 화소에 21% 를 내는 것이 최적이다
     (v5 · v6 의 가중 CE 는 2%). 선생인 DSCNN 의 선이 레이어마다 났다 안 났다 하는 것도 같은 쪽으로 민다.

6. **모델이 가장 크게 갈리는 곳은 B2 의 과용융 블록이다** (왼쪽 아래 정육면체, 5쪽). 용융 직후 사진에서 표면이 거칠고 도포 직후 사진에서는 파트 위에 검은 덩어리가 남는다.

7. **v6 의 Debris 가운데 6분의 1 은 판 위의 것이 아니다.** 세 자리 — (10, 487), (1181, 578), (1187, 866) — 가 다섯 빌드 (2021년 4–8월) 의 레이어 76–100개에서 똑같이 Debris 로 나온다.

   v6 의 Debris 는 전체로는 v5 의 4분의 1 넓이다 (0.069% / 0.30%) — v5 가 Debris 로 내던 Soot 영역이 SP 로 갔다.
8. **파트 영역은 네 모델이 같은 수준이다** (CAD 와의 IoU 0.80–0.81). 사람 GT 125 레이어만으로 배운 v6 가 ORNL 로 Stage 1 을 배운 v4 만큼 파트를 찾는다.

### 3.5 이 비교가 말하지 않는 것

- **정확도가 아니다.** v6 가 DSCNN 과 95% 같다는 것은 둘이 닮았다는 뜻이다. 둘은 같은 계열의 사람 주석 (Peregrine) 으로 배웠으므로 같은 버릇을 가질 수 있다.
- v4 는 이 다섯 빌드의 DSCNN 예측으로 Stage 1 을 배웠다 (B2–B5 학습, B1 검증). v4 와 DSCNN 이 닮은 것은 당연하고, v6 · v5 는 이 빌드의 사진을 한 장도 보지 않았다.
- 100 레이어는 다섯 빌드 17,582 레이어의 0.6% 다. 드문 사건 (도포 불량이 난 몇 레이어 등) 은 빠졌을 수 있다.
- 사진을 보고 적은 판단 (§3.4) 은 Claude 가 일부 레이어를 잘라 본 것이다. 사람의 확인이 아니다.
- 서빙 조건 (TTA · 후처리) 으로 돌린 것이 아니다.
